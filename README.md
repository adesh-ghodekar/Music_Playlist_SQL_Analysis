🎵 Music Playlist SQL Analysis


📋 Project Overview

This project explores a Music Playlist Database using PostgreSQL to derive meaningful insights about tracks, artists, albums, customers, and invoices.
It demonstrates SQL proficiency through real-world analytical queries and database design principles.


🗄️ Database Details

*Database Name: music_playlist

*Tool Used: PostgreSQL


🎯 Project Objectives

1.Analyze customer purchasing behavior.

2.Identify the most popular genres, artists, and tracks.

3.Understand revenue contributions by country and customer.

4.Explore playlist and track relationships.


💻 SQL Concepts Covered

Joins (INNER, LEFT, RIGHT, FULL)

Aggregate Functions (COUNT, SUM, AVG, MAX, MIN)

GROUP BY / HAVING Clauses

Subqueries & Common Table Expressions (CTEs)

Window Functions (RANK, DENSE_RANK, ROW_NUMBER)

String & Date Functions

Database Normalization and Relationships


📊 Insights & Findings

Rock and Alternative are the most purchased genres.

Top-selling artists: Queen, AC/DC, Metallica.

Highest revenue region: United States.

Average invoice total: approximately $5.75.


⚙️ How to Run This Project

1)Install PostgreSQL.

2)Create a new database named music_playlist.

3)Import the .sql file from the dataset folder into PostgreSQL.

4)Run the SQL scripts from the queries folder.

5)View results and explore insights
